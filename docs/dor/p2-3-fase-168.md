## 1. Lingkup Bisnis & Kriteria Keberterimaan

### 1.1 Hulu ke Hilir: Kontrak K8 HarvestLotSource & Agri Integration
- Kontrak K8 `Modules\Agri\Contracts\HarvestLotSource`:
  - `describe(string|int $collectionBatchId): ?array`
  - `availableGrams(string|int $collectionBatchId): int`
  - `consume(string|int $collectionBatchId, int $grams, string $idempotencyKey): void`
- Tabel pencatatan konsumsi aditif di modul Agri: `agri_collection_consumptions` (`id`, `collection_batch_id`, `grams_consumed`, `idempotency_key`, `created_at`, `updated_at`).
- Konsumsi bersifat idempoten: konsumsi ganda dengan idempotency key yang sama tidak menambah debet kuantitas.
- Sisa kuantitas lot Agri = kuantitas panen awal minus total gram yang dikonsumsi.

### 1.2 Modul Pemilik & Prefiks
- Pengolahan: `Manufacturing` (`mfg_`).
- Hulu: `Agri` (`agri_`).
- Modul `Food` (`food_`): hanya untuk merek / private label dan program gizi (`food_brands`, `food_products`, `food_batch_nutrition`).

### 1.3 Optimasi Blending LP & Neraca Massa (Manufacturing)
- Optimasi formulasi pencampuran komoditas menggunakan Two-Phase Simplex `Modules\Shared\Domain\Algorithms\Lp\RationalSimplex` dan `IntegerBlendRounder`:
  - Vektor prompt:
    * Lot A (Rp 9.000/kg, 12% protein, 14% air, stok 600 kg)
    * Lot B (Rp 7.500/kg, 9% protein, 12% air, stok 700 kg)
    * Lot C (Rp 8.000/kg, 11% protein, 16% air, stok 500 kg)
    * Target batch: 1.000 kg, protein $\ge 10,5\%$, air $\le 14\%$.
    * Solusi optimum unik: A = 250 kg, B = 375 kg, C = 375 kg; Biaya total = Rp 8.062.500.
  - Deteksi spesifikasi mustahil (infeasible constraints) $\to$ melempar status INFEASIBLE disertai sertifikat Farkas Lemma.
- Invarian Neraca Massa:
  - $\sum \text{gram lot input} = \text{gram output jadi} + \text{gram susut/by-product}$.
  - Toleransi neraca massa 0% toleransi bocor tanpa pencatatan.

### 1.4 Genealogi Graf & Traceability Recall (D168-2)
- Traversal maju (forward: lot bahan mentah $\to$ produk jadi di pasar) dan mundur (backward: produk di tangan konsumen $\to$ lot panen petani) menggunakan `Modules\Shared\Domain\Algorithms\Graph\GenealogyTraversal`.
- BFS traversal menghasilkan sertifikat penutupan hash-chain yang diverifikasi setara dengan oracle DFS independen.

### 1.5 Nilai Gizi Produk (Food)
- Nilai gizi per 100g (kalori, protein, lemak, karbohidrat, sodium) dihitung otomatis dari komposisi bahan baku batch pengolahan dengan pembulatan HalfUp 1 desimal.

### 1.6 Audit Dua Sumber & Fixture Korupsi
- Command `food:audit` (`Modules\Food\Console\Commands\AuditFoodCommand`):
  - Memastikan neraca massa klop pada seluruh batch.
  - Memastikan tidak ada over-consumption lot Agri.
  - Memastikan batch export grade mematuhi standar parameter laboratorium.
- Fixture korupsi `FoodAuditCorruptionFixture` terdaftar di `AuditCommandRegistry`.
