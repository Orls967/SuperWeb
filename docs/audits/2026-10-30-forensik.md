2. **`config/modules.php`**:
   - `shared_kernel_namespaces`: 3 → 16 → **LEBIH LONGGAR (P0)**. Mengikutsertakan Model Eloquent (`Core\Domain\Models\Vehicle`) dan Event domain modul bisnis. Tindakan: **Kembalikan** ke 3 kernel sah asli; entri lain wajib memiliki DECISIONS terjustifikasi.

3. **`app/Quality/ArchScan/Rules/MissingForeignKeyRule.php`**:
   - Token check: Index / Morphs dianggap foreign key constraint → **LEBIH LONGGAR (P1)**. Tindakan: **Kembalikan** agar hanya constraint foreign key nyata yang diterima.
